## Purpose

This document lists the software applications that are approved for installation on PRL Site Solutions Ltd company devices. Staff must not install software outside this list without prior approval from the MD or IT Administrator.

---

## Installation Approval Process

1. Staff identify a business need for software not on this list
2. Request is made to the MD or IT Administrator by email
3. MD/IT Administrator assesses the software for:
   - Business justification
   - Vendor legitimacy and support status
   - Security implications
4. If approved, the MD/IT Administrator installs the software or grants permission
5. Approved software is added to this list
6. Unapproved software must not be installed — Windows SmartScreen and standard user account restrictions enforce this technically

---

## Software Not Permitted

- Unlicensed or pirated software
- Software from unknown or untrusted vendors
- P2P file sharing applications
- Remote access tools not approved by the MD
- Any software that has reached end-of-life / is no longer supported
